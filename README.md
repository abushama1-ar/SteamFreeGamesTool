# SteamFreeGamesTool

أداة واجهة رسومية (WPF) بلغة C# تم تطويرها كمشروع تجريبي لإدارة ملفات المشروع "Nova" وتسهيل بناء نسخة سطحية للتعامل مع أرشيفات وملفات داخل مجلدات النظام للتطوير والاختبار.

⚠️ تنبيه قانوني

- لا أستطيع المساعدة في الترويج أو توثيق أو توجيه استخدام الأدوات التي تُستخدم لمخالفة القوانين أو تجاوز حماية البرامج (مثل تفعيل ألعاب أو توزيع تراخيص بشكل غير قانوني). استخدام هذا المشروع لأي غرض يخالف شروط خدمة أي منصة أو القوانين المحلية قد يكون غير قانوني ومخالف للأخلاق التقنية.
- هذا المستودع يحتوي على كود يُجري عمليات على ملفات نظامية؛ لا تشغّل أي أداة أو رمز في بيئة إنتاجية أو على حاسوبك الأساسي دون فهم كامل للمخاطر وبشكل قانوني وآمن.

نبذة سريعة

SteamFreeGamesTool هو مشروع WPF بسيط مبني على .NET يقدّم واجهة لسحب أرشيفات (ZIP) ومعالجة ملفات داخليّة ضمن مشروع "Nova"، بالإضافة إلى واجهة لعرض وإدارة ملفات محددة ضمن مجلدات متعلقة بالمشروع.

الميزات (موجز)

- واجهة رسومية (WPF) مبسطة.
- سحب وافلات ملفات ZIP لمعالجة محتوى الأرشيف.
- نسخ ملفات من مجلد مصدر داخل المشروع إلى مجلدات النظام (تستخدم لأغراض تطوير/اختبار).
- عرض قائمة الملفات المتوفرة داخل مجلدات المشروع.
- زر لإعادة تشغيل تطبيق خارجي (مثال: Steam) — يستخدم لأغراض التطوير فقط.

المتطلبات

- نظام تشغيل: Windows (لأن المشروع يستخدم WPF).
- .NET SDK: net10.0 أو ما يتوافق مع `TargetFramework` في ملف المشروع.
- أدوات: Visual Studio 2022/2023 أو dotnet CLI.

بناء وتشغيل (للمطورين)

1. استنخِب (clone) المستودع إلى جهازك.
2. افتح المجلد في Visual Studio أو استخدم dotnet CLI:
   - `dotnet restore`
   - `dotnet build`
   - `dotnet run` (أو تشغيل المشروع من داخل Visual Studio)

ملاحظة: هذا المشروع يتضمن عمليات وصول إلى ملفات على النظام. قم بتشغيله في بيئة اختبارية ومع صلاحيات مناسبة فقط وعند الضرورة.

هيكل المشروع (موجز)

- MainWindow.xaml / MainWindow.xaml.cs — الواجهة الرئيسية والمنطق.
- App.xaml / App.xaml.cs — إعدادات تطبيق WPF.
- SteamFreeGamesTool.csproj — إعدادات المشروع وTargetFramework.
- nova/ — مجلد موارد داخلي (قد يحتوي ملفات تُنسخ أثناء التوزيع).
